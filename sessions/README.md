# Session uploads

Each person copies their Cursor chats for this project into a subfolder named after them, then commits and pushes. GitHub keeps every upload in this folder.

```text
sessions/
  abhiram/
  your-name/
```

Chats are local to each computer. Copy the `agent-transcripts` folder for this workspace. These files include the full chat, so leave out anything you would not share with the team.
