Connect your Bots

Waypoint's five Bots, one Manager and four workers, are Grok Bots you set up in your own Grok Bot app. This page has everything to paste: the connector, your key, and each Bot's first message.

1. Add Waypoint as a connector

In Grok Bot, send this to your first Bot. If your app has a Plugins or Connectors screen with "custom MCP server", the same address and header go there.


            

              
              
              
            

            

          

        

      

      

        

          

            
2. Create the five Bots

            
Make a new Bot for each, give it the name shown, and paste its message as the first thing you say. Only the Manager gets a schedule: it starts the others. No message has your key in it, so each Bot can be shared as a template.

          

          

            

          

        

      

      

        

          

            
3. Let Check now wake them

            
Optional. Send the message to the Manager, then paste the webhook address and key it gives you. After that, Check now on your Brief starts a real run instead of a simulated one.

          

          

            

            

              
            

            

              

                
                
              

              

                
                Kept on the server. It is never shown again after you save.
                
              

              

              

                
                
              

              

            

          

        

      

      

        

          

            
4. Check it worked

          

          

            
Ask the Manager to "run the night now". Within a few minutes your Brief should show each Bot with a time under it, and lines in Checked for you that do not say simulated.

            
Bots share one cloud computer and its sign-ins, so treat the key like a password. Make a new key here if it leaks; the old one stops working at once.
