Connect your Bots

Waypoint's five Bots, one Manager and four workers, are Grok Bots that live in your own Grok Bot app. Install each one from its template, give it your key when it asks, and the team starts checking for you.

1. Copy your key

Each Bot asks for this key when you install it, and uses it to reach Waypoint at the address shown. It speaks for you and nobody else, so treat it like a password.

Setting a Bot up by hand instead

If you are not using a template, send this to the Bot first. If your app has a Connectors screen with "custom MCP server", the same address and header go there.


              

                
              

            

          

        

      

      

        

          

            
2. Install the five Bots

            
Open each template and install it in Grok Bot. Its setup asks for your key in a masked field and adds the Waypoint connector for you. Start with the Manager: it holds the team's one schedule and starts the others. No template has a key in it.

          

          

            

          

        

      

      

        

          

            
3. Let Check now wake them

            
Optional. Send the message to the Manager, then paste the webhook address and key it gives you. After that, Check now on your Brief starts a real run instead of a simulated one.

4. Check it worked

          

          

            
Ask the Manager to "run the night now". Within a few minutes your Brief should show each Bot with a time under it, and lines in Checked for you that do not say simulated.

            
Bots share one cloud computer and its sign-ins, so treat the key like a password. Make a new key here if it leaks; the old one stops working at once.
